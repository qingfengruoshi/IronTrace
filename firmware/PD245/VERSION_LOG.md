## ★ v131 —— 当前最优版本（温度控制封版）

**bin：14792 字节，md5 `19B2B3E15EDFD9C36D85C2017AE6C5E8`**

这是目前为止最完善、最稳定的一版，温度控制子系统全部完成。

### 温控性能实测（黑匣子数据）

| 设定温度 | 稳态范围 | 峰峰值 | 实际功率占用 |
|---|---|---|---|
| 200°C | 198 ~ 203 | **5°C** | 1.4% |
| 300°C | 297 ~ 303 | **6°C** | 2.6% |
| 400°C | 397 ~ 403 | **6°C** | 4.5% |

- 达到设计基线手册标称 ±2°C 同一量级
- **启动过冲**：从 +7~10°C 降至 +1~2°C（用户实测：「设定 300 升到 299 就停止加热，跳到 300，没有过冲感」）

### PID 参数（按实测数据整定，非设计基线原值）

```
Kp = 2.0      （比例）
Ki = 0.010    （积分，已含 100Hz 采样率折算）
Kd = 1.0      （微分，另有 ×2.0 系数 → 有效 2.0/°C差）
输出 0~100 → LM 百分比限幅 → ×319/100 转 CCR4
```

**为什么不用设计基线的 Kp=10 / Kd=20**：设计基线参数针对 0-100 全量程；我们在 LM=15% 限幅下等效增益被放大 6.7 倍，照抄会持续 bang-bang（实测峰峰 14°C）。

### 本版关键机制

| 机制 | 说明 |
|---|---|
| **测量窗口采样** | 同步到 PWM 断电相尾部采样，避开导通噪声 |
| **设计基线温度换算表** | 节点 19/415/1050/1800/2625/3050 → 25/100/200/300/400/450°C |
| **8 样本滚动滤波** | 平滑 ADC 噪声（设计基线同款） |
| **抗积分饱和** | 输出顶 LM 上限且误差>0 → 冻结积分；到 0 且误差<0 → 冻结。治启动过冲 |
| **拔头检测 3 拍去抖** | 阈值 3501（对齐设计基线异常区）+ 连续 3 拍（30ms）。单点噪声尖峰不再误触发三角 |
| **显示防抖** | 刷屏用 `g_disp_temp`（控制环滤波值），不直读裸 ADC；斜率限制 30°C/10ms；上电 <8 拍不刷屏 |
| **黑匣子** | 10Hz 降采样 1024 点（≈102 秒），拔头瞬间写入 Flash 页 124/125/126，掉电不丢 |
| **五档状态机** | 未插入 / 就绪 / 休眠 / 待机 / 深度，含 30s→待机、5min→深度的递进关机链 |
| **休眠检测** | SC7A20 10Hz，运动量 Σ\|Δ轴\|≥25 判定，静止 12.5s 入睡，连续 3 拍运动唤醒 |

### 已修复的重要问题（本版不再出现）

- ✅ 插拔烙铁头概率重启（内阻测量脉冲的 8A 峰值 → 改为加热中被动计算 R=VBUS/I）
- ✅ 加热中假「未插入」三角（单点噪声尖峰 3711 误判 → 3 拍去抖）
- ✅ 拔头后延迟 1~2 秒才显示三角（→ 30ms 内响应）
- ✅ 上电闪一下室温（→ 前 8 拍不刷屏）
- ✅ 显示偶发 0°C（→ 不再直读裸 ADC）
- ✅ 拔头瞬间黑匣子数据丢失（→ 落盘 Flash，不再依赖 SRAM）

### 已知的 LM 关系

- PID 与 LM **无关**：稳态输出 d≈8.2（300°C），远低于 LM=15 上限，限幅不触发
- 只要 LM > 稳态所需功率，**稳态精度完全一致**
- LM 调高只影响：升温更快、带载回温更强、过冲可能略增 1~2°C
- **实际红线**：100W PD 充电器建议 LM ≤ 50~60%（满占空比约 8A/160W，超出会触发 OCP）

## 霍尔（磁吸休眠）支持说明 —— 当前硬件未安装

**现状**：PD210 原理图（2024-09-01 版）网络表中无 HALL 相关网络，本机硬件无霍尔传感器，因此休眠方式仅实现「运动 / 关闭」。

**若要加装霍尔，需要做三件事**：

1. **硬件**：选用开关型霍尔（如 A3144 / 低功耗 AH1815 等，输出开漏或推挽），VCC 接 3.3V、GND 接地，OUT 接到一个空闲 GPIO（建议避开已用引脚：
   - 已用：PA3(HEAT)、PA5/PA6(ADC)、PB1(ADC)、PA7/PB0/PB2/PB10/PB15(LCD)、GYRO 与 HUSB238 的 I2C 引脚
   - 推荐可选：PB3 / PB4 / PB5 / PB6 / PB7 等）
2. **固件**：在 `main.c` 顶部定义 `#define HALL_PORT GPIOB` / `#define HALL_PIN 4`，并把 `sleep_mode` 的磁吸分支（当前未实现）接上：
   ```c
   // 磁吸休眠：靠近磁铁 → 暂停加热；远离 → 恢复
   if (sleep_mode == 2 && hall_detected()) { tip_paused = 1; }
   else if (sleep_mode == 2 && tip_paused) { tip_paused = 0; }
   ```
   霍尔输入需配置为上拉输入（开漏霍尔）或浮空输入（推挽霍尔）。
3. **菜单**：SET 页的「休眠方式」增加第三项「磁吸」（当前只有 运动/关闭）。

> 说明：无霍尔硬件时选择「磁吸」不会造成误休眠（引脚上拉后恒为"远离"状态），因此该选项可以安全保留在菜单里。

## v134 —— CAL 校准页（阶段 B-1）

**bin：15592 字节，md5 `687689A5BC0F8C90D7C429957E76E1CB`**

### 功能
- **全局温度偏置** `cal_ofs`（-50..+50°C），叠加在换算结果上（显示与 PID 同步生效）
- 持久化：存入 `settings_t.reserved`，掉电保存
- 页面布局（160x40）：
  `
  CAL  OFS:+0C
  NOW: 25C      TGT:200C
  LR:ADJ        CS:HOLD
  `
- 操作：
  - 左/右键：偏置 -1 / +1（长按连续）
  - 中键长按：加热到 200°C（再按一次停止）
  - 中键单击：返回菜单

### 校准原理与验证方法
1. **无需加热即可验证功能**：进入 CAL 页，用左/右键改 OFS，观察 `NOW` 同步变化（±1 变化即 1°C）→ 证明校准通路生效
2. **加热验证**：中键长按 → 自动加热到 200°C，用外部温度计或熔点法比对
3. **无温度计的参考点**：
   - 63/37 有铅焊锡熔点 **183°C**
   - SAC305 无铅焊锡熔点 **217~220°C**
   - 沸水 **100°C**（注意防水）
4. **方向**：若实际温度比显示**高**，则 OFS 设**正值**（例：显示 200、实测 205 → OFS=+5）

### 局限
- 这是**全局单点偏置**，不是设计基线的分段校准。若低温段与高温段误差方向不同，只能折中
- 实测当前 200/300/400°C 精度 ±3°C，一般情况下**不需要校准**
