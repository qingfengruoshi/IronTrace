## 关键教训（踩过的坑，按重要性排）

| # | 教训 | 后果 |
|---|---|---|
| 1 | **PowerWriter 缓存旧镜像**：同路径换内容不重读 | 烧录的永远是旧版；v39-v46 全部白测。**对策：唯一文件名** |
| 2 | **烧录后芯片停在算法入口不重启** | 屏幕是 LCD GRAM 旧画面、按键全无效——"死机假活"。**对策：调试器强制复位或断电重启** |
| 3 | **md5 不变 = 编译失败**：链接器静默用旧 .o | 改了代码但二进制没变。**对策：每次核对 md5 与上版不同** |
| 4 | **PowerShell 变量大小写不敏感**：`$f` 与 `$F` 是同一个变量 | 循环把参数数组覆盖 → 全量编译失败 |
| 5 | **mojibake 注释不可用于精确匹配** | Edit/replace 静默失败。**对策：改代码用 Python 行级操作或 ASCII 锚点** |
| 6 | **看门狗与用户操作互相打架** | 看门狗 1.2s 周期把记忆挡位写回，覆盖用户的挡位请求 → "9V 写死"（v52 停用看门狗后立刻正常） |
| 7 | I2C 写等待掩码 TXIS(0x02) vs RXNE(0x04) 混淆 | 读事务永远超时 |
| 8 | I2C 读事务缺 AUTOEND → 不发 STOP → 总线挂死 | 首读之后全部 I2C 死 |
| 9 | 字符串缓冲区 `b[16]` 截断 | 22 字符的诊断行只显示 15 字符 |

## 已确认的硬件/协议事实（供后续参考）

- **HUSB238**：I2C 地址 0x08（写 0x10 / 读 0x11）；选挡 = 写 0x08 的高 4 位（码 0x10/0x20/0x30/0x80/0x90/0xA0）；GO = 0x09 bit0 置位后清零
- **SC7A20**：I2C 地址 0x18（扫描 0x18-0x1F）；WHO_AM_I 寄存器 0x0F
- **I2C 引脚**：PB6=SCL、PB9=SDA（软件位操作，读通写通）
- **设计基线 reg_write**：`f(handle, dev=0x10, reg, count=1, {&val, 1, timeout=10})`——含重试语义
- **设计基线 I2C 初始化**（0x896C 区域）：CR1=0x100002A8、OAR1=0x1F4、TIMINGR=0x1F4
- **充电器 PDO 广播**：0x2B = 5V/9V/15V/20V（绿挡）；12V/18V 不广播（红挡）
- **PWLink 与充电器不能同时使用**（供电二选一）
